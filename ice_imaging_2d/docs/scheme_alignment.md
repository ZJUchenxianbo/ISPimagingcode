# 研究方案与当前实现的对应关系

本说明核对《冰层双界面定性成像_完整研究方案》PDF第7–13、28–29页。该文档是研究方案，不能把候选表达式当作已闭合算法或已证明定理。

## 已纠正的偏离

原主线为六个参数的中心差分灵敏度、相关指标和正则化 Gauss–Newton。它借鉴了4.6节，但不是4.2–4.5节的双界面 TD-DSM。原代码和结果保留在显式 `--mode sensitivity` 对照下，旧 `--mode dual` 报错说明迁移；默认入口显示方案实现状态，不启动正演或重建。

冰厚、收发阵列、材料和10–20 kHz条件不因本次纠偏改变。当前粗糙几何中0.1 m为正弦单边振幅、0.2 m为峰谷差，此定义必须与实际条件核对，不能默认将“20 cm粗糙度”解释成RMS。自由表面候选不成为方案默认模型。

## 第4.3节：已实现的离散反传播算子

令 d 为观测减参考的声压，dn d为相同参考相减后的接收点法向导数。取测线法向 n=+ez，与现有 solver.gradient 的物理+z约定一致。正向因果核记Gpp(x_r,z,s)，s≥0，接收点法向导数为dn_r Gpp。

方案第9页写成G(t−tau)，并明确要求时间反向Green或等价伴随传播。代码使用其伴随时间反向约定：

```
V_s(z,t) = sum_r w_r int [dn d_rs(tau) conj Gpp(x_r,z,tau-t)
                         - d_rs(tau) conj dn_r Gpp(x_r,z,tau-t)] d tau.
```

这是固定核的离散边界配对，不是完整声–弹界面Green恒等式的证明。两项均使用同一正法向，法向整体翻转会使V整体变号。接收点采用实际非均匀位置梯形权重，时间积分亦使用梯形权重。单接收点用计数权重1，不宣称其近似连续孔径积分。

设观测时间tau=tau0+i*dt、核时间s=k*dt。相关输出t=tau0+(i−k)*dt，保留完整有符号时差轴；不裁成原始接收时间轴，不将接收回波窗直接当作反传播时间窗。实现使用线性相关而非循环FFT卷积，并对复数核取共轭。输出形状为 `(source, sample, backprop_time)`，不对source提前相加。

目前仅接收**水侧采样点的Gpp**。冰内不能用标量声压测试核冒充弹性位移场。输出只有虚拟场，没有补偿场、最终界面指标或高度估计。不会把未补偿能量改名为方案的I_layer、I_b或I_t。

## 固定背景核文件契约

`background_green.py`只验证输入契约，不是核生成器。目前仓库**没有经过物理验收的耦合背景核文件**，因而不能立即运行完整方案。

NPZ使用以下字段，不允许pickle：

| 字段 | 形状或含义 |
|---|---|
| `gpp` / `normal_gpp` | `(sample, receiver, lag)`，因果单位脉冲响应及接收点法向导数 |
| `lag` | 均匀递增，从0开始，与观测相同dt |
| `points` | `(sample,2)`，物理坐标[x,z]，本算子限水侧 |
| `receiver_x`、`array_z` | 与输入Cauchy数据完全一致的测线 |
| `metadata_json` | 标量JSON，包含下述来源与约定 |

元数据：`schema=ice-cauchy-green-v1`、`response=causal_impulse`、`normal=positive_z`、`background=air-elastic_ice-water`、`derivative=receiver_normal`、`sample_medium=water`。`reference_signature`由参考数据中的config_json和geometry_json计算；`validation_report`说明核的物理验证来源。此来源字段不是代码已经证明核正确的认证。

为避免源单位歧义，输入契约明确使用 `source_equation=pressure_rate_rhs`：流体满足 `p_t + K div(v) = q`，核对应空间/时间单位脉冲q，单位与该源约定一致；法向导数多一个1/m。与用二阶波动方程右端定义的Green函数之间须做源算子/时间导数换算，不能直接混用。**该源约定仍需与推导出的耦合Green恒等式核对**，契约不代表已经完成规范化推导。

现有模拟记录包含实际宽带源脉冲，不能直接作为单位脉冲核使用；不能不说明地反卷积或再次卷积。源规范化、位移/速度转换、密度/牵引的对偶配对及正演/伴随源算子一致性都是背景核构建的必验项。仅有文件格式一致不代表这些已验收。

数据要求：观测和参考有相同的源、收发坐标、时间轴、物理配置和求解器版本；界面几何允许不同。梯度必须是法向导数。单条水平压力阵列只能近似切向导数，**不能通过沿阵列差分获得垂直法向导数**。仅压力实测数据需要独立推导pressure-only版本或增加垂向测量，当前程序拒绝静默替代。

## 尚未闭合的环节与后续推导

| 方案位置 | 缺少的数学/实现内容 | 必须先验证 |
|---|---|---|
| 4.2 | Gpp、Gup、空气声场及弹性应力双侧迹；一致源规范化 | 平层界面条件、互易性、因果性、源单位、独立离散收敛 |
| 4.3 | 从完整声–弹Green恒等式核实边界配对与常系数因子 | 任意测试函数上的离散伴随检验；不能只测数组相关正确 |
| 4.4 | 三层背景的全孔径核及有限孔径补偿场 | 全/有限孔径对照；单界面镜像定理不能直接照搬 |
| 4.5 下界面 | 参考曲线能量响应到实际高度的采样/几何提取规则 | 原式只在f0上取值，不能凭该式直接输出二维高度峰 |
| 4.5 上界面 | 位移与速度/加速度一致的界面匹配算子、双侧迹/跳跃条件及不同量纲的配对 | 原方案已提醒候选残差平方不自动聚焦；还须核对运动学条件的时间阶次 |
| 4.6 | 局部形状核的正演/伴随边界双线性形式 | 上下界面核的方向导数、单位、符号及聚焦；六个参数差分不是该局部核 |

下一步首先推导并验收平层背景核与上述对偶配对，再做下界面直接指标，最后构造上界面专用指标。这里存在真实的数学推导工作；不能通过恢复旧优化器、射线或Born近似来宣布完成。任何新增模型近似需明确说明并经用户确认。

## 当前验证及其边界

`experiments.direct_checks`将FFT实现与显式时域双重求和比较，检查复数共轭、时间滞后方向、法向翻转、非均匀接收权重、零残差、尾端不回卷及时间网格不匹配拒绝。它验证第4.3节离散算子实现，不证明Green核的物理正确或两个界面的成像聚焦。合成代数核仅在临时测试中使用，不保存为科研数据。
