# 首次反射 TD-DSM 与透射冰水界面

本阶段改变的是数据选择和成像实验，正演仍为水域声学BEM与冰层弹性Q4-FEM耦合，再经CQ生成时域数据。耦合模型允许冰水界面透射和冰内P/S波；上界面暂取已知平面。默认上表面零牵引近似，保留显式空气耦合的CPU正演选项。

令测线为 $\Gamma$，源点为 $y$，采样点为 $z$，沿用论文的 $\Phi_\chi$、$V^s$ 与校正场表示。将完整散射数据替换为

$$v_\chi^{s,(1)}(x,t;y)=w_1(x,t;y)\,[p_\chi(x,t;y)-p_\chi^i(x,t;y)].$$

声压与法向导数使用同一10–20 kHz滤波、同一时间窗和同一收发孔径。窗口中心仅由事先给定参考平面、收发几何与源脉冲中心决定，不读取真实边界。当前原始数据记录 $\partial_z p$；论文测线向下法向下 $\partial_\nu p=-\partial_z p$。

实现的有限时间Cauchy配对为

$$V^{s,(1)}(z,\tau;y)=\int_\Gamma\int_\tau^T
\left[\partial_\nu v_\chi^{s,(1)}(x,t;y)\Phi_\chi(x,t-\tau;z)
-v_\chi^{s,(1)}(x,t;y)\partial_\nu\Phi_\chi(x,t-\tau;z)\right]dt\,ds_x.$$

离散实现先截取测试核的 $[0,T)$ 样本，再补零做线性相关，保留 $0\le\tau<T$，同时保留内外两个时间积分的步长因子。测试核使用均匀水域二维Green函数与相同有效源脉冲；源和接收测线采用梯形权重。

以事先指定参考面构造论文型镜像校正 $V_{corr}^i$，计算三项：

$$I_0^{(1)}(z)=\int_{\Gamma_s}\int_0^T|V^{s,(1)}(z,\tau;y)|^2d\tau\,ds_y,$$
$$I^{(1)}(z)=\int_{\Gamma_s}\int_0^T|V^{s,(1)}(z,\tau;y)+V_{corr}^i(z,\tau;y)|^2d\tau\,ds_y,$$
$$I_{corr}(z)=\int_{\Gamma_s}\int_0^T|V_{corr}^i(z,\tau;y)|^2d\tau\,ds_y.$$

三项均保存原始能量与图像，图示同时提供共同尺度与各自归一化。冰底曲线取逐列峰值并做局部二次插值，不做基于真值的平滑或补偿系数调优。仅补偿指标用于检查参考面本身是否主导结果；全零指标不能被当成有效边界。

首次反射门控并非严格的模式分解。均匀水域核和镜像校正在弹性透射边界上的聚焦性质尚待验证，不能直接沿用原论文完整散射数据的理论结论。窗口宽度、先验参考面、阵列孔径、网格/CQ收敛及校正场占比都影响结果。软件检查通过不代表真实冰水边界已准确反演。

后续应先在正式10–20 kHz配置下检验平底与0.20 m竖向峰谷差粗糙冰底，比较三项指标、参考平面误差和预设窗宽敏感性，再研究未知上表面及整个冰层。历史低频图仅作归档，不代替这一验证。
